# CERTICHAIN
### Blockchain-Based Academic Certificate Verification System

CERTICHAIN is a proposed platform designed to make academic certificate verification more secure, transparent, and accessible.

## Phase 1: UI/UX Design & Static Frontend Development

This phase focuses on developing the static frontend interface using HTML5 and CSS3.

## Technologies Used
- HTML5
- CSS3

## Website Features
- Navigation bar
- Certificate ID input interface
- QR code image upload interface
- Sample certificate preview
- Academic verification features
- Responsive website layout

## Project Structure
- index.html
- style.css

## Current Phase
Phase 1: Static Frontend Development

Note: Certificate verification, QR scanning, and blockchain integration are not functional in this phase.
